클래스와 앱 질문

사진만으로 확실히 가르기 어려운 병은 대응이 같은 것끼리 묶었습니다. 묶은 안에서는 앱이 질문(JSON disambiguation)으로 세부 병명을 좁힙니다.

모델 클래스포함하는 병해충대응 등급앱 질문

spot 반점병세균구멍병, 검은별무늬병soonspot_split (잎에 구멍이 있는지 등)

반점병과 구멍·상처의 확률이 비슷하면(차이 0.2 미만) spot_vs_damage 질문을 추가로 띄웁니다.

구조와 서버 연결 방식

농민 앱: 봉지 벗긴 과실 사진→ 앱 서버 /analyze→ 과실 탐지 (팀 탐지기)→ 병해 분류 (이 모델)→ 결과 + 대응방안

사진 한 장으로 품질 예측과 병해충 판단을 같이 합니다. 모델은 서버에서 돌기 때문에 앱 용량에는 영향이 없습니다. 품질 모델(quality/base.py)과 같은 Protocol 방식이고, 설치·연동 예시·결과 필드 설명은 pest_model/deploy/README.md에 있습니다.

from peach_pest import ConvNeXtPestModel
pest_model = ConvNeXtPestModel("pest_convnext_exp7D.pt", "peach_pest_guide.json",
                               detector="fruit_yolo11n.pt")  # 공통 탐지기 박스를 쓰면 생략
pest = pest_model.predict(image_bytes, boxes=None)  # boxes: 원본 픽셀 [(x1,y1,x2,y2), ...]

전처리 (모델과 반드시 같아야 함, 코드에 포함)

  • 사진의 EXIF 회전 정보 반영, RGB
  • 과실 박스를 가로·세로 10% 넓혀 자르기
  • 짧은 변 288px로 리사이즈 후 중앙 288×288
  • ImageNet 정규화 (mean 0.485/0.456/0.406, std 0.229/0.224/0.225)

과실이 없는 사진

  • 과실 박스가 없으면 판정하지 않고 status: "no_fruit"와 다시 찍기 안내를 돌려줌
  • 너무 작은 박스(짧은 변 10% 또는 64px 미만)와 단색 크롭은 버림
  • 앱 앞단에서 복숭아 판별을 이미 한다면 이 장치는 이중 안전장치

새 사진에서는 병명 정확도 77% 안팎을 기대하세요. 같은 설정을 seed(학습 무작위성)만 바꿔 3번 학습하면 NCPMS 점수가 66~72로 흔들립니다. 배포 가중치의 81%는 그중 높은 쪽입니다. NCPMS가 89장뿐이라 몇 장 차이로 점수가 크게 움직입니다.

  • 팀 검수 test의 "기타" 149개는 세부 병명이 없어, 하나씩 다시 판정했습니다(구멍·상처 41, 부패병 21, 정상 19 등). 판단이 어려운 55개와 과실이 거의 안 보이는 8개는 평가에서 뺐습니다.
  • 탄저병은 팀 검수 test에서 대부분 부패병으로 판정됩니다. 둘 다 urgent 등급이라 앱의 대응 안내는 같습니다.

  • 가장 큰 개선은 라벨 정리에서 나왔습니다. 공개 데이터의 사진 단위 라벨이 한 사진의 모든 과실에 퍼져 있었고, "잿빛무늬병" 폴더에 미라 과실이나 다른 병이 섞여 있었습니다.
  • 지식 스무딩: 정답에 확률을 100% 몰아주지 않고, 헷갈리기 쉬운 짝(부패병↔탄저병, 반점병↔구멍·상처)에 일부를 나눠 학습합니다. 반점병 개선(11 → 16/17)과 오답 확신도 하락이 이 덕분입니다. 다만 반점병 16/17은 다른 seed에서 12~15였습니다.
  • 증상 증강(자르기·회전·뒤집기·약한 색 변화): 부패병 개선(31 → 34/42)에 기여했습니다.

5. 엉뚱한 단서와 데이터 누수 점검

공개 데이터(Islamia)의 증강 사본이 train과 test에 섞여 있어 원본 단위로 다시 나눴습니다. 촬영 거리(정상은 먼 사진, 병은 접사)로 구분하는 문제는 과실만 잘라서 보는 2단계 구조로 해결했습니다.

한계

미홍 정상 과실 오경보율을 아직 재지 못했습니다. 팀 검수 test의 정상 과실(다른 품종)은 125개 중 114개를 정상으로 유지했지만, 미홍 사진은 아직 없습니다.

탄저병은 출처에 따라 성능 차이가 큽니다(NCPMS 15/19, 팀 검수 test 6/15). 학습 크롭이 52개(검증 9개)뿐입니다. 놓친 것은 대부분 부패병으로 판정해 대응 등급은 같습니다.

세부 병명은 질문으로 나눕니다. 세균구멍병과 검은별무늬병, 충해와 열과·상처는 과실 사진만으로 확실히 가르기 어렵습니다.

학습하지 않은 병해충(바이로이드, 매미충 알 등)도 5클래스 중 하나로 판정될 수 있습니다. 결과는 항상 "의심"으로 표시하고 농업기술센터 문의를 함께 안내합니다.

과실이 아닌 사진: 잎·땅처럼 무늬가 있는 사진을 탐지기가 과실로 잡으면 판정됩니다. 앱 앞단의 복숭아 판별과 함께 쓰는 것을 전제로 합니다.

잎·가지·봉지 겉면은 AI로 판정하지 않습니다. 과실 판정 결과에 맞춰 "함께 확인할 곳"을 안내합니다.
